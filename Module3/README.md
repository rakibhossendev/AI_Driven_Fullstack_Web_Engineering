## Adantage of line css
- Load Fast
- Highest Priority
- Instant Fixes
- No File Switching

## Disadvantage 
- It cannot be reuse
- Repetitive Code
- Hard to Update
- Increased HTML Weight

## Internal CSS
Internal css write before head tag.
```html
<head>
    <style>
        tag_name{
            <!--Style-->
        }
    </style>
</head>
```
