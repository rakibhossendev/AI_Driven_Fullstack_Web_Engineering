আজকের Challenge:

Vanilla JavaScript দিয়ে একটি ছোট Interactive Dashboard তৈরি করার চেষ্টা করো।

Dashboard-এ-

- একটি Counter থাকবে

- একটি Input থাকবে

- Button Click করলে UI Update হবে

- Data `localStorage`-এ Save হবে

- Page Reload করলে Data আবার Load হবে

- `setTimeout()` বা `setInterval()` দিয়ে কোনো ছোট Feature থাকবে

- একটি API থেকে Data Fetch করে Page-এ Display করবে
